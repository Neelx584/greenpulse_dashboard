
# GreenPulse Dashboard

**GreenPulse** is an interactive urban analytics dashboard that explores how **green space, tree canopy, and environmental factors** influence **wellbeing, stress, and respiratory health** across London boroughs.

Built using **Streamlit**, the dashboard combines open datasets with a simulation tool to help users understand how changes in urban nature could impact public health outcomes.

## Dashboard Purpose

GreenPulse was designed to:
* Visualise environmental and wellbeing inequalities across London
* Demonstrate how urban greening interventions may affect health indicators
* Provide a **conference-ready, interactive decision-support tool**
* Lay foundations for future **real-time sensor integration (ESP32)**

----------------------------------------------------------------------

## Key Features

-> **Interactive London map** by borough  
-> **Green space & tree canopy simulations**
-> **Wellbeing, stress, and respiratory risk indicators**
-> **Slider-based policy simulations**
-> **Clear visual feedback** (green ↑ positive, red ↓ negative)
-> **Modular design for adding future datasets and live sensors**
